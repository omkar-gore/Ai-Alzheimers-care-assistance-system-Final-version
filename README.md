# CareMate: Alzheimer's Patient Assistance & Care Management System

## Project Description

CareMate is a full-stack application designed to assist Alzheimer's patients, caregivers, and doctors in managing daily care, medications, schedules, tasks, appointments, memory aids, and communication.

## Features

* Three user roles: Patient, Caregiver, and Doctor, with role-based dashboards and access.
* Authentication using password hashing and JWT.
* Patient dashboard with medications, schedules, tasks, SOS alerts, and a memory book.
* Caregiver dashboard to manage patient care, medications, schedules, and alerts.
* Doctor dashboard for patient monitoring, appointments, reports, and communication.
* AI assistant with fallback responses for Alzheimer's-friendly support.
* Cognitive screening activities and assessment history.
* Mind games and exercise suggestions.
* Responsive user interface built with Tailwind CSS and Bootstrap.
* Demo mode with sample users and data for demonstrations.

## Technology Stack

* **Frontend:** React.js, Vite, Tailwind CSS, Bootstrap 5, Axios, React Router, Lucide Icons.
* **Backend:** Node.js, Express.js.
* **Database:** MongoDB and Mongoose.
* **Authentication:** JSON Web Tokens (JWT) and bcrypt.
* **AI Assistant:** Google Gemini API integration with fallback responses.

## Project Structure

* `client/` — React frontend application.
* `server/` — Node.js and Express backend.
* `README.md` — Project documentation.

## Getting Started

1. Clone the repository.
2. Install the frontend and backend dependencies.
3. Configure the required environment variables.
4. Start the backend server.
5. Start the frontend development server.

Refer to the project configuration and environment example files for the specific commands and settings.

## Project Goal

CareMate aims to support Alzheimer's patients and their caregivers through accessible digital tools for daily care management, memory assistance, cognitive activities, and doctor-patient coordination.
